Privacidad de 3CB Micro Apps

3CB Micro Apps está diseñada para realizar cálculos y generar documentos directamente en el navegador del usuario.

Procesamiento local

Los datos que escribes en las herramientas se procesan localmente y no se envían intencionalmente a servidores de 3CB. No solicitamos cuentas ni contraseñas.

Almacenamiento

El navegador puede almacenar los archivos de la aplicación mediante Cache API para permitir su funcionamiento offline. El tema visual puede guardarse en el almacenamiento local del navegador. Los datos de trabajo no se guardan automáticamente.

Descargas y enlaces externos

Los documentos o imágenes que generes se descargan bajo tu decisión. Si abres enlaces externos, se aplicarán las políticas del sitio de destino.

Alcance

Esta declaración describe el funcionamiento previsto de esta versión. Antes de una publicación comercial definitiva, revisa el código, las dependencias y las prácticas de alojamiento para verificar que no se incorporen servicios de terceros.
